# 夜霜秘密基地

**把相遇、心意与陪伴，留在同一个基地。**

夜霜秘密基地是面向夜霜粉丝的微信小程序。你可以查询兽聚、参与基地活动与许愿、给夜霜写信并查看回信，也可以查看守护记录、管理头衔与装扮、了解骑士身份和周边服务。

**资料更新：2026-11-02。** 本页依据当前项目及已于 2026-10-29 上传的 **1.9.2 开发版**整理；开发版上传不等于微信正式版上线。实际运行版本、开放功能与参与条件以微信内展示为准。

## 从哪里开始

| 入口 | 可以做什么 |
| --- | --- |
| **首页** | 从常用入口进入兽聚日历、活动中心、许愿池、写信、守护榜与表情包。 |
| **参与** | 集中查找活动、写信和许愿入口，继续查看兽聚与守护记录。 |
| **发现** | 浏览夜霜周边、系列表情包、大事记及联创伙伴。 |
| **我的** | 查看个人守护档案、雪花资产、头衔装扮、骑士身份与自己的相关记录。 |

## 参与前了解这些

- **写信与回信：**写信免费，仅发送给夜霜运营后台，不在小程序内公开展示，也不提供用户间发帖、评论或私信。是否回复由夜霜决定。
- **白雪花与许愿：**白雪花通过基地降雪、活动与任务等免费路径获得；许愿按当期规则及有效愿力抽取结果，不保证获奖。金雪花不能用于许愿。
- **守护与身份：**守护值按已认证平台与认可支持记录计算；会员身份不会直接增加守护值。头衔、卡面装扮与榜单展示分别管理。
- **骑士与周边：**年度会员权益、开通状态、骑士群、赠礼及独立限时优惠以小程序内公示为准；展示界面不代表相关服务已开放。
- **兽聚资料：**日历仅展示已收录的公开活动。图中活动为虚构示例，真实日期、场地和安排请继续核对主办方公告。
